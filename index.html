How Bedrock Box works with Minecraft

Cómo funciona Bedrock Box con Minecraft

  • You need your own copy of Minecraft: Java Edition. Bedrock Box is a mod, not a copy of the game. KaoTik Games does not distribute Minecraft.
  • Sign-in is done with Microsoft's official flow. The player signs in with their own Microsoft account on Microsoft's website, using a device code. KaoTik Games never sees or stores the password.
  • Ownership is checked. The launcher only starts Minecraft for accounts that own Minecraft: Java Edition.
  • Game files come from the official servers. Minecraft and its libraries are downloaded from Mojang's own servers; Forge from its official source.
  • The mod can also be installed by hand into the player's existing Minecraft and played from the official Minecraft Launcher.
  • Hace falta tu propia copia de Minecraft: Java Edition. Bedrock Box es un mod, no una copia del juego. KaoTik Games no distribuye Minecraft.
  • El inicio de sesión es el oficial de Microsoft. El jugador entra con su propia cuenta de Microsoft en la web de Microsoft, con un código de dispositivo. KaoTik Games nunca ve ni guarda la contraseña.
  • Se comprueba que el juego es tuyo. El lanzador solo abre Minecraft a las cuentas que tienen Minecraft: Java Edition.
  • Los archivos del juego vienen de los servidores oficiales. Minecraft y sus librerías se descargan de los servidores de Mojang; Forge, de su fuente oficial.
  • El mod también se puede instalar a mano en el Minecraft que ya tenga el jugador y jugarse desde el Minecraft Launcher oficial.

Accounts and privacy

Cuentas y privacidad

  • A KaoTik Games account is an email address and a password. We send a one-time code by email to confirm the address when the account is created.
  • Passwords are stored only as salted hashes. We do not sell or share account data.
  • Microsoft sign-in is used only to start Minecraft for the player. The resulting session stays on the player's computer.
  • Una cuenta de KaoTik Games es un correo y una contraseña. Al crearla enviamos un código de un solo uso por correo para confirmar la dirección.
  • Las contraseñas se guardan solo como resúmenes con sal. No vendemos ni compartimos datos de las cuentas.
  • El inicio de sesión de Microsoft se usa únicamente para abrir Minecraft al jugador. Esa sesión se queda en su equipo.
